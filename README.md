# SheGuard – Women Safety Mobile App

SheGuard is an Android-based women’s safety application designed to help users send emergency alerts and share their location with trusted contacts.

It provides manual SOS, voice-triggered alerts, emergency contact management, location sharing, and nearby police station lookup.

## Features
- Emergency SOS button
- Voice-triggered SOS
- Shake-based emergency activation
- Fall detection
- Emergency SMS and location sharing
- Nearby police station locator
- Emergency siren/alarm

## Technologies Used
- Kotlin
- Android Studio
- Android Sensor APIs
- SpeechRecognizer
- GPS / Fused Location Provider
- SmsManager
- Google Maps
